# Thamanya Sans

Place the licensed local font files here using these names:

- `ThamanyaSans-Regular.woff2`
- `ThamanyaSans-Medium.woff2`
- `ThamanyaSans-Bold.woff2`

Then add local `@font-face` declarations at the top of `static/css/variables.css`; the design system already uses `Thamanya Sans` as its first font family.
